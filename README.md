# Morphix's Media Builder
### ДЛЯ ИСПОЛЬЗОВАНИЯ НУЖЕН ЭКЗЕКУТОР ЛУА КОДА С ПОДДЕРЖКОЙ WEBSOCKET
### Строитель изображений и видео в Roblox плейсе Build A Boat For Threasure
1 Запускаете executor с поддержкой websocket, запускаете роблокс, запускаете pythonserver (в релизе есть .exe сервер)
1. Создайте папку где вам удобно
2. Закиньте туда pythonserver.exe (из release)
3. Создайте папку с названием "workspace" (без ковычек)
4. Закиньте в эту папку что хотите
5. Запустите роблокс, pythonserver.exe и executor с поддержкой websocket
6. Запустите скрипт через ваш executor луа кода.
7. Скрипт автоматически просканирует workspace и возьмет от туда файлы
8. Выбирайте изображение/видео и настраивайте как хотите!
9. Чтобы добавить изображение/видео нужно перезапускать луа скрипт.
